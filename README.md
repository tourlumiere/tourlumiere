# Tour Lumière Cybernétique — prototype en données réelles

A working reconstruction of Nicolas Schöffer's programme for the unbuilt Tour Lumière Cybernétique at La Défense (1962–1973), run on present-day Paris data.

The tower's computer programme (Appendix 5), the 1973 simulation régimes (Appendix 6), the cellule d'indifférence and the night schedule are implemented after Schöffer, *La Tour Lumière Cybernétique* (Paris: Denoël/Gonthier, 1973). The structure is traced from the façade and section sheet on p. 132. Inputs come from public, browser-accessible sources (Open-Meteo, EMSC, Ville de Paris, Santé publique France, ECB, Radio France, Bluesky, Wikimedia). See the Notes tab for every substitution and interpretive decision.
